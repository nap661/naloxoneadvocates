Naloxone Advocates – WordPress Theme (Elementor‑ready)
=========================================================

This custom theme provides prebuilt templates for Home, About, Training & P2P, Resources, Volunteer, and Contact.

INSTALL
-------
1. Zip this folder and upload in **WordPress → Appearance → Themes → Add New → Upload Theme**.
2. Activate.
3. Go to **Appearance → Menus** and assign menus to **Primary** and **Footer**.
4. Create these pages and assign templates (Page → Template dropdown):
   - Home → **Home (Prebuilt)** (set as **Settings → Reading → Your homepage displays → A static page → Home**)
   - About → **About (Prebuilt)**
   - Training & P2P → **Training & P2P (Prebuilt)**
   - Resources → **Resources (Prebuilt)**
   - Volunteer → **Volunteer (Prebuilt)**
   - Contact → **Contact (Prebuilt)**

RECOMMENDED PLUGINS
-------------------
- **Elementor** (page builder)
- **The Events Calendar** + **Event Tickets** (sessions & RSVP/tickets)
- **WPForms Lite / Forminator** (contact/volunteer forms)

NOTES
-----
- All colours & spacing live in `assets/css/main.css`.
- Replace stats, dates, phone, and email as needed in the templates.
